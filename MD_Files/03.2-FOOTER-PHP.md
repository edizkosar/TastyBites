# 03.2 — Layout Footer (`includes/footer.php`)

## 📋 File Info
- **Path:** `includes/footer.php`
- **Type:** Layout include (outputs HTML)
- **Depends on:** `includes/config.php` (for `BASE_URL`, `APP_NAME`) — already loaded by header
- **Used by:** Every user-facing page that included `header.php`

## 🎯 Purpose
Close `<main>`, render the site footer, include Bootstrap JS bundle + the project's small `main.js`, and close `</body></html>`.

## 📦 Required Behavior

1. Close `<main>` opened by `header.php`.
2. Render a `<footer class="tb-footer mt-5">` with restaurant info (address, phone, hours, copyright).
3. Include Bootstrap 5.3.3 JS bundle CDN.
4. Include `<script src="{BASE_URL}/assets/js/main.js"></script>`.
5. Close `</body></html>`.

No PHP logic. Just HTML + 1–2 PHP constant echoes.

## 🚫 Must NOT Do
- No additional `<main>` open tags.
- No `session_start()` / DB connection (already done in header chain).
- No inline `<script>` blocks with business logic.
- No closing `?>` tag at end of file.
