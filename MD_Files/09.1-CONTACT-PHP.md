# 09.1 — Contact Form (`contact.php`)

## 📋 File Info
- **Path:** `contact.php` (project root)
- **Type:** Public page. GET form + POST handler in one file.
- **Depends on:** `includes/db.php`, `includes/helpers.php`, `includes/auth_helpers.php`, layout includes
- **Used by:** All visitors (anonymous or logged in)

## 🎯 Purpose
A public contact form that inserts a row into the `messages` table. On success, a flash thanks the user. For logged-in users, the name and email are pre-filled.

## 📦 Required Behavior

### On GET
- Render an empty form.
- If `isLoggedIn()` → pre-fill `full_name` and `email` from the session (read `full_name` from DB if not already in session — but since `user_name` IS the full name, that's enough; we don't have email in session, so we fetch it).

Actually, to keep things simple: pre-fill only `full_name` from `currentUserName()`. The user can fill in email manually. (No extra DB query needed.)

### On POST
1. Trim inputs into `$old`.
2. Validate (rules below).
3. Push errors to `$errors[]`.
4. If valid → INSERT into `messages` with `is_read = 0`.
5. Flash success → redirect `/contact.php` (Post-Redirect-Get).

### Form fields
| Name | Required | Validation |
|---|---|---|
| `full_name` | yes | 2..100 chars |
| `email` | yes | Valid format |
| `subject` | yes | 3..150 chars |
| `body` | yes | 10..2000 chars |

### Right-side info block
Two-column layout: form on the left, restaurant contact info on the right (address, phone, hours — same as About page).

## 🚫 Must NOT Do
- Don't actually send email (out of scope) — just save to DB.
- Don't require login.
- Don't store extra columns beyond the schema.
- Don't add CAPTCHA.

## 📐 Code Skeleton

```php
<?php
require_once __DIR__ . '/includes/db.php';
require_once __DIR__ . '/includes/helpers.php';
require_once __DIR__ . '/includes/auth_helpers.php';

$errors = [];

// Pre-fill name if logged in (email left blank — only stored in DB)
$old = [
    'full_name' => currentUserName() ?? '',
    'email'     => '',
    'subject'   => '',
    'body'      => '',
];

if (currentMethod() === 'POST') {
    $old['full_name'] = trim($_POST['full_name'] ?? '');
    $old['email']     = trim($_POST['email'] ?? '');
    $old['subject']   = trim($_POST['subject'] ?? '');
    $old['body']      = trim($_POST['body'] ?? '');

    if ($old['full_name'] === '' || mb_strlen($old['full_name']) < 2 || mb_strlen($old['full_name']) > 100) {
        $errors[] = 'Full name is required (2–100 chars).';
    }
    if ($old['email'] === '' || !isValidEmail($old['email'])) {
        $errors[] = 'A valid email is required.';
    }
    if ($old['subject'] === '' || mb_strlen($old['subject']) < 3 || mb_strlen($old['subject']) > 150) {
        $errors[] = 'Subject is required (3–150 chars).';
    }
    if ($old['body'] === '' || mb_strlen($old['body']) < 10 || mb_strlen($old['body']) > 2000) {
        $errors[] = 'Message is required (10–2000 chars).';
    }

    if (empty($errors)) {
        $stmt = $db->prepare(
            "INSERT INTO messages (full_name, email, subject, body)
             VALUES (?, ?, ?, ?)"
        );
        $stmt->bind_param('ssss',
            $old['full_name'], $old['email'], $old['subject'], $old['body']);
        $stmt->execute();
        $stmt->close();

        setFlash('Thanks for reaching out! We will get back to you soon.', 'success');
        redirect('/contact.php');
    }
}

$pageTitle = 'Contact Us';
require_once __DIR__ . '/includes/header.php';
?>

<h1 class="mb-4">Contact Us</h1>

<div class="row g-4">
    <div class="col-md-7">
        <?php if (!empty($errors)): ?>
            <div class="alert alert-danger">
                <ul class="mb-0">
                    <?php foreach ($errors as $err): ?><li><?= e($err) ?></li><?php endforeach; ?>
                </ul>
            </div>
        <?php endif; ?>

        <form method="post" action="<?= BASE_URL ?>/contact.php" novalidate>
            <div class="mb-3">
                <label class="form-label" for="full_name">Full Name</label>
                <input type="text" id="full_name" name="full_name" class="form-control"
                       value="<?= e($old['full_name']) ?>" required>
            </div>
            <div class="mb-3">
                <label class="form-label" for="email">Email</label>
                <input type="email" id="email" name="email" class="form-control"
                       value="<?= e($old['email']) ?>" required>
            </div>
            <div class="mb-3">
                <label class="form-label" for="subject">Subject</label>
                <input type="text" id="subject" name="subject" class="form-control"
                       maxlength="150" value="<?= e($old['subject']) ?>" required>
            </div>
            <div class="mb-3">
                <label class="form-label" for="body">Message</label>
                <textarea id="body" name="body" rows="6" class="form-control"
                          maxlength="2000" required><?= e($old['body']) ?></textarea>
                <small class="text-muted">10–2000 characters.</small>
            </div>
            <button type="submit" class="btn btn-primary">Send Message</button>
        </form>
    </div>

    <div class="col-md-5">
        <div class="card">
            <div class="card-body">
                <h5 class="card-title">Visit Us</h5>
                <p class="mb-1"><strong>Address</strong></p>
                <p class="mb-3">123 Bistro Lane, Foodtown, FT 12345</p>

                <p class="mb-1"><strong>Phone</strong></p>
                <p class="mb-3">+1 (555) 123-4567</p>

                <p class="mb-1"><strong>Email</strong></p>
                <p class="mb-3">hello@tastybites.local</p>

                <p class="mb-1"><strong>Opening Hours</strong></p>
                <p class="mb-0">Mon–Sun · 11:00 – 22:00</p>
            </div>
        </div>
    </div>
</div>

<?php require_once __DIR__ . '/includes/footer.php'; ?>
```

## 🧹 Clean Code Reminders
- Post-Redirect-Get pattern: a successful submission ends with `redirect()` to avoid duplicate sends on refresh.
- Pre-fill only the name from session — keeps it simple and avoids an extra DB query.
- `mb_strlen` for accurate character counts (UTF-8).
