# 01.1 — Database Schema (`database/schema.sql`)

## 📋 File Info
- **Path:** `database/schema.sql`
- **Type:** SQL script (DDL + seed data)
- **Depends on:** Nothing (this is the foundation)
- **Used by:** All PHP files (indirectly, via MySQL)

## 🎯 Purpose
A single SQL file that drops, recreates, and seeds the entire `tastybites` database. Re-runnable: dropping at the top makes it safe to import repeatedly.

## 📦 Required Behavior

1. Drop database `tastybites` if it exists.
2. Create database `tastybites` with `utf8mb4 / utf8mb4_unicode_ci`.
3. `USE tastybites;`
4. Create **6 tables** (defined below) using `InnoDB`.
5. Insert seed data (admin user, test user, categories, menu items, tables, sample reservations).

## 🚫 Must NOT Do
- No additional tables (no `audit_log`, `settings`, etc.).
- No triggers, stored procedures, or views.
- No password stored in plain text.
- No `CREATE USER` / `GRANT` statements (use default `root`).
- No comments that include real passwords (only hashes go in the SQL).

## 📐 Code Skeleton

```sql
-- TastyBites — database schema and seed data
-- Re-runnable: drops and recreates the database from scratch.

DROP DATABASE IF EXISTS tastybites;
CREATE DATABASE tastybites
    DEFAULT CHARACTER SET utf8mb4
    DEFAULT COLLATE utf8mb4_unicode_ci;
USE tastybites;

-- ============================================================
-- Tables
-- ============================================================

CREATE TABLE users ( ... ) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
CREATE TABLE menu_categories ( ... ) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
CREATE TABLE menu_items ( ..., FOREIGN KEY (category_id) REFERENCES menu_categories(id) ON DELETE CASCADE ) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
CREATE TABLE tables ( ... ) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
CREATE TABLE reservations (
    ...,
    INDEX idx_reservation_lookup (table_id, reservation_date, reservation_time),
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
    FOREIGN KEY (table_id) REFERENCES tables(id) ON DELETE RESTRICT
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
CREATE TABLE messages ( ... ) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

## 🧹 Clean Code Reminders
- One section header comment per logical block.
- Constraints inline with the column where simple; foreign keys at the bottom of the `CREATE TABLE`.
- Hashes go on a single line (do not break with newlines).
- File ends with a single trailing newline.
