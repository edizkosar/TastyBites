# 02.4 — Auth Helpers (`includes/auth_helpers.php`)

## 📋 File Info
- **Path:** `includes/auth_helpers.php`
- **Type:** Backend include, function library, no output
- **Depends on:** `includes/config.php` (session), `includes/helpers.php` (redirect, setFlash)
- **Used by:** Login/register pages, protected pages, admin pages

## 🎯 Purpose
Authentication and authorization guards that read `$_SESSION` state set by `auth/login.php`. Provides the `requireLogin()` / `requireAdmin()` guards used by every protected page.

## 📦 Required Behavior

Define exactly the 6 functions listed below. This module READS session state. It does NOT set login state — that happens in `auth/login.php`.

The session keys this module reads:
- `$_SESSION['user_id']` — int
- `$_SESSION['user_name']` — string
- `$_SESSION['user_role']` — string, either `'user'` or `'admin'`

## 🔧 Interface — Functions Exposed

```php
/** True if a user is logged in. */
function isLoggedIn(): bool

/** True if the logged-in user has admin role. */
function isAdmin(): bool

/** Returns the current user's id, or null if not logged in. */
function currentUserId(): ?int

/** Returns the current user's display name, or null if not logged in. */
function currentUserName(): ?string

/** If not logged in, redirect to login.php and exit. */
function requireLogin(): void

/** If not admin, redirect to home with a danger flash and exit. */
function requireAdmin(): void
```

## 🚫 Must NOT Do
- Do not query the DB. These functions read session only.
- Do not modify `$_SESSION` write keys (`user_id`, etc.). Only read them.
- No HTML output.
- No closing `?>` tag.

## 📐 Code Skeleton

```php
<?php
/**
 * TastyBites — Authentication Helpers
 * Session-based identity reads and access guards.
 */

require_once __DIR__ . '/config.php';
require_once __DIR__ . '/helpers.php';

/** True if a user is logged in. */
function isLoggedIn(): bool
{
    return isset($_SESSION['user_id']) && $_SESSION['user_id'] > 0;
}

/** True if the logged-in user has admin role. */
function isAdmin(): bool
{
    return isLoggedIn() && ($_SESSION['user_role'] ?? '') === 'admin';
}

/** Returns the current user's id, or null if not logged in. */
function currentUserId(): ?int
{
    return isLoggedIn() ? (int)$_SESSION['user_id'] : null;
}

/** Returns the current user's display name, or null if not logged in. */
function currentUserName(): ?string
{
    return isLoggedIn() ? ($_SESSION['user_name'] ?? null) : null;
}

/** If not logged in, redirect to login.php and exit. */
function requireLogin(): void
{
    if (!isLoggedIn()) {
        setFlash('Please log in to continue.', 'warning');
        redirect('/auth/login.php');
    }
}

/** If not admin, redirect to home with a danger flash and exit. */
function requireAdmin(): void
{
    if (!isAdmin()) {
        setFlash('Admin access required.', 'danger');
        redirect('/index.php');
    }
}
```

## 🧹 Clean Code Reminders
- Each function ≤ 7 lines.
- `requireAdmin()` does NOT call `requireLogin()` first — admin check via `isAdmin()` already covers both ("logged in AND role is admin").

3. Open `http://localhost/tastybites/_authtest.php` while logged out.
   Expected:
   ```
   Logged in: bool(false)
   Admin: bool(false)
   User ID: NULL
   Name: NULL
   ```

4. Manually set session in the test file to simulate login:
   ```php
   <?php
   require_once __DIR__ . '/includes/config.php';
   $_SESSION['user_id'] = 99;
   $_SESSION['user_name'] = 'Test User';
   $_SESSION['user_role'] = 'user';
   require_once __DIR__ . '/includes/auth_helpers.php';
   var_dump(isLoggedIn()); // true
   var_dump(isAdmin());    // false
   echo currentUserId() . PHP_EOL;       // 99
   echo currentUserName() . PHP_EOL;     // Test User
   ```

5. Repeat step 4 with `user_role = 'admin'` → `isAdmin()` returns `true`.

6. Test guard — replace test file body with:
   ```php

   requireLogin();
   echo "Should not reach here when logged out.";
   ```
   Open in browser. Expected: redirected to `/tastybites/auth/login.php` (which won't exist yet — a 404 is acceptable; the redirect itself proves the guard works).

7. **Delete `_authtest.php` after verifying.**
