# 02.3 — Helper Functions (`includes/helpers.php`)

## 📋 File Info
- **Path:** `includes/helpers.php`
- **Type:** Backend include, function library, no output
- **Depends on:** `includes/config.php` (for `BASE_URL` and session)
- **Used by:** Most PHP files

## 🎯 Purpose
A small, procedural library of pure helper functions used everywhere: escaping, redirecting, flash messages, and common formatting.

## 📦 Required Behavior

Define exactly the functions in the Interface section below. Each function does one thing. No global state except `$_SESSION` for flash messages.

## 🔧 Interface — Functions Exposed

```php
/** Escapes a string for safe HTML output. */
function e(?string $value): string

/** Redirects to a BASE_URL-relative path and exits. */
function redirect(string $path): void

/** Stores a one-shot flash message in the session. */
function setFlash(string $message, string $type = 'success'): void
// $type ∈ {'success', 'danger', 'warning', 'info'}

/** Returns and clears the current flash message, or null if none. */
function getFlash(): ?array
// returns ['message' => string, 'type' => string] or null

/** Formats a numeric price as "$12.50". */
function formatPrice($value): string

/** Formats a (date, time) pair as "Mon, 24 Jun 2025 · 19:30". */
function formatReservationDateTime(string $date, string $time): string

/** True if the string is a syntactically valid email. */
function isValidEmail(string $email): bool

/** Returns the current request method in UPPERCASE. */
function currentMethod(): string
```

## 🚫 Must NOT Do
- No DB queries (helpers are pure).
- No HTML output / `echo`.
- No class definitions — procedural functions only.
- No closing `?>` tag.
- Do NOT define `requireLogin()` / `requireAdmin()` here — those live in `auth_helpers.php`.

## 📐 Code Skeleton

```php
<?php
/**
 * TastyBites — Helper Functions
 * Pure procedural helpers: escaping, redirect, flash, formatting.
 */

require_once __DIR__ . '/config.php';

/** Escapes a string for safe HTML output. */
function e(?string $value): string
{
    return htmlspecialchars((string)($value ?? ''), ENT_QUOTES | ENT_SUBSTITUTE, 'UTF-8');
}

/** Redirects to a BASE_URL-relative path and exits. */
function redirect(string $path): void
{
    header('Location: ' . BASE_URL . $path);
    exit;
}

/** Stores a one-shot flash message in the session. */
function setFlash(string $message, string $type = 'success'): void
{
    $_SESSION['flash'] = ['message' => $message, 'type' => $type];
}

/** Returns and clears the current flash message, or null if none. */
function getFlash(): ?array
{
    if (!isset($_SESSION['flash'])) {
        return null;
    }
    $flash = $_SESSION['flash'];
    unset($_SESSION['flash']);
    return $flash;
}

/** Formats a numeric price as "$12.50". */
function formatPrice($value): string
{
    return '$' . number_format((float)$value, 2, '.', ',');
}

/** Formats a (date, time) pair as "Mon, 24 Jun 2025 · 19:30". */
function formatReservationDateTime(string $date, string $time): string
{
    $dt = DateTime::createFromFormat('Y-m-d H:i:s', $date . ' ' . $time);
    if (!$dt) {
        $dt = DateTime::createFromFormat('Y-m-d H:i', $date . ' ' . substr($time, 0, 5));
    }
    if (!$dt) {
        return $date . ' ' . $time;
    }
    return $dt->format('D, d M Y') . ' · ' . $dt->format('H:i');
}

/** True if the string is a syntactically valid email. */
function isValidEmail(string $email): bool
{
    return filter_var($email, FILTER_VALIDATE_EMAIL) !== false;
}

/** Returns the current request method in UPPERCASE. */
function currentMethod(): string
{
    return strtoupper($_SERVER['REQUEST_METHOD'] ?? 'GET');
}
```

## 🧹 Clean Code Reminders
- One docblock per function.
- No function exceeds 10 lines.
- `e()` handles `null` gracefully (it's the most-used helper; must never crash).
- `formatReservationDateTime` accepts both `'19:00'` and `'19:00:00'` time strings — MySQL returns the longer form, HTML inputs send the shorter one.

## 🧪 Health Check

### Steps


2. Create temporary `_helpertest.php` at project root:
   ```php
   <?php
   require_once __DIR__ . '/includes/helpers.php';
   echo e('<script>alert(1)</script>') . PHP_EOL;
   echo e(null) . PHP_EOL;                              // empty string, no warning
   echo formatPrice(12.5) . PHP_EOL;                    // $12.50
   echo formatPrice('1234.5') . PHP_EOL;                // $1,234.50
   echo formatReservationDateTime('2025-06-24', '19:30') . PHP_EOL;
   echo formatReservationDateTime('2025-06-24', '19:30:00') . PHP_EOL;
   var_dump(isValidEmail('a@b.com'));                   // true
   var_dump(isValidEmail('not-an-email'));              // false

   setFlash('Test message', 'success');
   $f = getFlash();
   ```

   ```
   bool(false)

   NULL
   ```
