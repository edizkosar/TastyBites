# 00.3 — Tech Stack (Locked Decisions)

> **Status:** Rules file. These technology choices are FIXED.

---

## 🔒 The Stack

| Layer | Tool | Version | Notes |
|-------|------|---------|-------|
| Server-side language | **PHP** | 8.x (procedural) | No framework. Course requires server-side. |
| Database | **MySQL** | 5.7+ / 8.x | Via `mysqli` extension. NOT PDO. |
| Web server | **Apache** | 2.4+ | XAMPP / WAMP / MAMP all fine |
| Frontend CSS | **Bootstrap 5.3** | via CDN | No local copy, no SCSS |
| Frontend Icons | **Bootstrap Icons** | via CDN | Used sparingly |
| Frontend JS | **Vanilla JavaScript** | ES6+ | Tiny — just confirm dialogs + alert auto-dismiss |
| Char encoding | **UTF-8** | utf8mb4 in MySQL | Everywhere |

## 📦 CDN URLs (use exactly these)

In `includes/header.php`:

```html
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
<link href="https://cdn.jsdelivr.net/npm/bootstrap-icons@1.11.3/font/bootstrap-icons.css" rel="stylesheet">
```

In `includes/footer.php`:

```html
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
```

If a version-pinned CDN URL doesn't load, swap minor version (`5.3.3` → `5.3.x`) but never switch to a different framework.

## 🚫 Tech NOT In Use

These are explicitly banned. Do not introduce them, even "just for one feature":

- ❌ Composer / Packagist
- ❌ Laravel / Symfony / CodeIgniter / any framework
- ❌ PDO (we use `mysqli` for course-typical syntax)
- ❌ npm / Yarn / package.json
- ❌ React / Vue / Angular / Svelte
- ❌ jQuery (vanilla JS is enough for our needs)
- ❌ SCSS / SASS / LESS / Tailwind
- ❌ Bootstrap 4 or earlier
- ❌ Twig / Smarty / Blade or any template engine
- ❌ Sessions in DB / Redis (default file-based PHP sessions)
- ❌ Email libraries (PHPMailer, etc.) — see scope boundaries

## 🔧 PHP Extensions Required

These come bundled with stock XAMPP/WAMP — no special setup:

- `mysqli`
- `session`
- `mbstring` (for safe string handling)
- `filter` (for `filter_var(..., FILTER_VALIDATE_EMAIL)`)

No additional `php.ini` tweaks required.

## 🧪 Local Dev Setup (for the team)

1. Install XAMPP (or WAMP/MAMP).
2. Start Apache + MySQL services.
3. Copy the project folder into `htdocs/` so the URL becomes `http://localhost/tastybites/`.
4. Open phpMyAdmin → Import → select `database/schema.sql` → Go.
5. Open `http://localhost/tastybites/` in browser.

`includes/config.php` defaults match the XAMPP defaults (`root` / no password / `localhost`).

## 📜 PHP Settings (set in code, not php.ini)

`includes/config.php` does this at the top:

```php
error_reporting(E_ALL);
ini_set('display_errors', '1');
date_default_timezone_set('Europe/Istanbul');
```

This keeps the project portable — no need to edit anyone's `php.ini`.
