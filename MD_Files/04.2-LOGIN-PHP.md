# 04.2 — Login Page (`auth/login.php`)

## 📋 File Info
- **Path:** `auth/login.php`
- **Type:** Public page (GET form + POST handler)
- **Depends on:** `includes/db.php`, `includes/helpers.php`, `includes/auth_helpers.php`, layout
- **Used by:** Anonymous visitors; targets of redirect after `requireLogin()`

## 🎯 Purpose
Display a login form, verify credentials, set session identity on success, and redirect to the appropriate dashboard.

## 📦 Required Behavior

### On GET
- If user is already logged in → redirect to `/index.php`.
- Render an empty form.

### On POST
1. Trim email and password.
2. Validate both non-empty and email format.
3. Look up user: `SELECT id, full_name, password_hash, role FROM users WHERE email = ? LIMIT 1`.
4. If row missing OR `password_verify()` fails → push single generic error: **"Invalid email or password."** (Do not say which one is wrong.)
5. On success:
   - `session_regenerate_id(true);`
   - Set `$_SESSION['user_id']`, `$_SESSION['user_name']`, `$_SESSION['user_role']`.
   - Set flash: `Welcome back, {full_name}!`
   - If role is `admin` → redirect `/admin/dashboard.php`.
   - Else → redirect `/user/dashboard.php`.

### Form fields
| Name | Required | Validation |
|---|---|---|
| `email` | yes | Format check |
| `password` | yes | Non-empty (don't enforce length on login) |

## 🚫 Must NOT Do
- Do NOT differentiate "email not found" vs "wrong password" in the error.
- Do NOT store `password_hash` in `$_SESSION`.
- Do NOT remember-me cookies / persistent tokens (out of scope).
- Do NOT echo `$_POST['password']` anywhere.
- Do NOT skip `session_regenerate_id(true)` — it's a security must.

## 📐 Code Skeleton

```php
<?php
require_once __DIR__ . '/../includes/db.php';
require_once __DIR__ . '/../includes/helpers.php';
require_once __DIR__ . '/../includes/auth_helpers.php';

if (isLoggedIn()) {
    redirect('/index.php');
}

$errors = [];
$old = ['email' => ''];

if (currentMethod() === 'POST') {
    $old['email'] = trim($_POST['email'] ?? '');
    $password     = $_POST['password'] ?? '';

    // Light validation first
    if ($old['email'] === '' || $password === '') {
        $errors[] = 'Please enter both email and password.';
    } elseif (!isValidEmail($old['email'])) {
        $errors[] = 'Invalid email or password.';
    } else {
        $stmt = $db->prepare(
            "SELECT id, full_name, password_hash, role
             FROM users WHERE email = ? LIMIT 1"
        );
        $stmt->bind_param('s', $old['email']);
        $stmt->execute();
        $res = $stmt->get_result();
        $user = $res->fetch_assoc();
        $stmt->close();

        if (!$user || !password_verify($password, $user['password_hash'])) {
            $errors[] = 'Invalid email or password.';
        } else {
            session_regenerate_id(true);
            $_SESSION['user_id']   = (int)$user['id'];
            $_SESSION['user_name'] = $user['full_name'];
            $_SESSION['user_role'] = $user['role'];

            setFlash('Welcome back, ' . $user['full_name'] . '!', 'success');
            if ($user['role'] === 'admin') {
                redirect('/admin/dashboard.php');
            }
            redirect('/user/dashboard.php');
        }
    }
}

$pageTitle = 'Log In';
require_once __DIR__ . '/../includes/header.php';
?>

<div class="row justify-content-center">
    <div class="col-md-5">
        <h1 class="mb-4">Log In</h1>

        <?php if (!empty($errors)): ?>
            <div class="alert alert-danger">
                <?= e($errors[0]) ?>
            </div>
        <?php endif; ?>

        <form method="post" action="<?= BASE_URL ?>/auth/login.php" novalidate>
            <div class="mb-3">
                <label class="form-label" for="email">Email</label>
                <input type="email" id="email" name="email" class="form-control"
                       value="<?= e($old['email']) ?>" required>
            </div>
            <div class="mb-3">
                <label class="form-label" for="password">Password</label>
                <input type="password" id="password" name="password" class="form-control" required>
            </div>
            <button type="submit" class="btn btn-primary w-100">Log In</button>
            <p class="mt-3 text-center">
                No account? <a href="<?= BASE_URL ?>/auth/register.php">Register here</a>.
            </p>
        </form>
    </div>
</div>

<?php require_once __DIR__ . '/../includes/footer.php'; ?>
```

## 🧹 Clean Code Reminders
- Only ONE generic error message is ever shown for failed login.
- All session writes happen AFTER `session_regenerate_id(true)`.
- The flash message uses the user's full_name as it was stored.
