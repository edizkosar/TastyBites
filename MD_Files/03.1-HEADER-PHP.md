# 03.1 — Layout Header (`includes/header.php`)

## 📋 File Info
- **Path:** `includes/header.php`
- **Type:** Layout include (outputs HTML)
- **Depends on:** `includes/db.php`, `includes/helpers.php`, `includes/auth_helpers.php`
- **Used by:** Every user-facing page (`index.php`, `menu.php`, `about.php`, auth pages, user/admin pages, etc.)

## 🎯 Purpose
Render the top of every page: `<!doctype html>`, `<head>` (with CDN links), the navbar (with auth-aware menu), and the flash message bar. Open `<main class="container py-4">` for the page body.

## 📦 Required Behavior

1. At the top (before any output), `require_once` the 3 includes.
2. Read `$pageTitle` (set by the including page); default to `'TastyBites'`.
3. Read flash via `getFlash()` BEFORE opening HTML.
4. Output the full document head + navbar + flash bar + open `<main>`.

## 🔧 Interface — HTML Structure

### `<head>`
- `<meta charset="utf-8">`
- `<meta name="viewport" content="width=device-width, initial-scale=1">`
- `<title>` — `{$pageTitle} — {APP_NAME}`
- Bootstrap 5.3.3 CSS via CDN
- Bootstrap Icons 1.11.3 via CDN
- `<link rel="stylesheet" href="{BASE_URL}/assets/css/style.css">`

### Navbar (Bootstrap `navbar-dark`, `bg-primary` (will be overridden by CSS to wine red))
**Brand:** `TastyBites` → `BASE_URL . '/index.php'`

**Always-visible links:** Home, Menu, About, Contact, Reservation

**Right side (conditional):**
- Logged OUT: "Login" + "Register" buttons.
- Logged IN as user: greeting `Hi, {first name}` + "My Reservations" + "Logout".
- Logged IN as admin: greeting `Admin: {name}` + "Admin Panel" + "Logout".

### Flash bar
Renders only when `$flash !== null`:
```html
<div class="container mt-3">
    <div class="alert alert-{type}" role="alert">{message}</div>
</div>
```

### Open main wrapper
```html
<main class="container py-4">
```
The footer closes this `<main>`.

## 🚫 Must NOT Do
- No DB queries here.
- No inline `<style>` blocks.
- No `<form>` elements.
- No `session_start()` (already started in `config.php`).
- No closing `</main>` or `</body>` (the footer does that).
- No JS imports in `<head>` — JS goes in footer.

## 📐 Code Skeleton

```php
<?php
require_once __DIR__ . '/db.php';
require_once __DIR__ . '/helpers.php';
require_once __DIR__ . '/auth_helpers.php';

$pageTitle = $pageTitle ?? APP_NAME;
$flash = getFlash();
$firstName = currentUserName() ? explode(' ', currentUserName())[0] : null;
?>
<!doctype html>
<html lang="en">
<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title><?= e($pageTitle) ?> — <?= APP_NAME ?></title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
    <link href="https://cdn.jsdelivr.net/npm/bootstrap-icons@1.11.3/font/bootstrap-icons.css" rel="stylesheet">
    <link href="<?= BASE_URL ?>/assets/css/style.css" rel="stylesheet">
</head>
<body>

<nav class="navbar navbar-expand-lg navbar-dark">
    <div class="container">
        <a class="navbar-brand" href="<?= BASE_URL ?>/index.php"><?= APP_NAME ?></a>
        <button class="navbar-toggler" type="button" data-bs-toggle="collapse"
                data-bs-target="#mainNav" aria-controls="mainNav" aria-expanded="false"
                aria-label="Toggle navigation">
            <span class="navbar-toggler-icon"></span>
        </button>
        <div class="collapse navbar-collapse" id="mainNav">
            <ul class="navbar-nav me-auto">
                <li class="nav-item"><a class="nav-link" href="<?= BASE_URL ?>/index.php">Home</a></li>
                <li class="nav-item"><a class="nav-link" href="<?= BASE_URL ?>/menu.php">Menu</a></li>
                <li class="nav-item"><a class="nav-link" href="<?= BASE_URL ?>/about.php">About</a></li>
                <li class="nav-item"><a class="nav-link" href="<?= BASE_URL ?>/contact.php">Contact</a></li>
                <li class="nav-item"><a class="nav-link" href="<?= BASE_URL ?>/reservation.php">Reservation</a></li>
            </ul>
            <ul class="navbar-nav ms-auto">
                <?php if (!isLoggedIn()): ?>
                    <li class="nav-item">
                        <a class="btn btn-outline-light btn-sm me-2" href="<?= BASE_URL ?>/auth/login.php">Login</a>
                    </li>
                    <li class="nav-item">
                        <a class="btn btn-light btn-sm" href="<?= BASE_URL ?>/auth/register.php">Register</a>
                    </li>
                <?php elseif (isAdmin()): ?>
                    <li class="nav-item">
                        <span class="navbar-text me-3">Admin: <?= e(currentUserName()) ?></span>
                    </li>
                    <li class="nav-item">
                        <a class="btn btn-outline-light btn-sm me-2" href="<?= BASE_URL ?>/admin/dashboard.php">Admin Panel</a>
                    </li>
                    <li class="nav-item">
                        <a class="btn btn-light btn-sm" href="<?= BASE_URL ?>/auth/logout.php">Logout</a>
                    </li>
                <?php else: ?>
                    <li class="nav-item">
                        <span class="navbar-text me-3">Hi, <?= e($firstName) ?></span>
                    </li>
                    <li class="nav-item">
                        <a class="btn btn-outline-light btn-sm me-2" href="<?= BASE_URL ?>/user/dashboard.php">My Reservations</a>
                    </li>
                    <li class="nav-item">
                        <a class="btn btn-light btn-sm" href="<?= BASE_URL ?>/auth/logout.php">Logout</a>
                    </li>
                <?php endif; ?>
            </ul>
        </div>
    </div>
</nav>

<?php if ($flash !== null): ?>
    <div class="container mt-3">
        <div class="alert alert-<?= e($flash['type']) ?>" role="alert">
            <?= e($flash['message']) ?>
        </div>
    </div>
<?php endif; ?>

<main class="container py-4">
```

(Note: file is open-ended. The page body and footer close `<main>` / `<body>` / `<html>`.)

## 🧹 Clean Code Reminders
- All output of user data passes through `e()`.
- The auth section uses `if/elseif/else` — exactly three branches.
- One `<?php` block per logical chunk; HTML is not interrupted mid-tag.
- Indent HTML consistently (4 spaces).
