# 05.3 — About Page (`about.php`)

## 📋 File Info
- **Path:** `about.php` (project root)
- **Type:** Static public page (no DB)
- **Depends on:** `includes/config.php` (via header), layout includes
- **Used by:** All visitors

## 🎯 Purpose
Static "About Us" page with restaurant background, location info, and team cards. Demonstrates the layout works without any DB query.

## 📦 Required Behavior

1. Set `$pageTitle = 'About Us'`.
2. Render an `<h1>` heading.
3. Two-column row: left = story paragraphs; right = image placeholder.
4. "Visit Us" info card with address / phone / hours.
5. "Meet the Team" row with 3 team-member cards.
6. Include header and footer.

## 🔧 Interface — HTML Structure

```html
<h1 class="mb-4">About TastyBites</h1>

<div class="row align-items-center mb-5">
    <div class="col-md-7">
        <!-- 2-3 paragraphs of story -->
    </div>
    <div class="col-md-5">
        <!-- image or placeholder block -->
    </div>
</div>

<div class="card mb-5">
    <div class="card-body">
        <h4 class="card-title">Visit Us</h4>
        <!-- address, phone, hours -->
    </div>
</div>

<h2 class="mb-3">Meet the Team</h2>
<div class="row g-4">
    <!-- 3 cards: .col-md-4 each -->
</div>
```

## 🚫 Must NOT Do
- No DB queries.
- No login-aware variants.
- No external API calls.
- No iframe embeds (Google Maps, etc.).

## 📐 Code Skeleton

```php
<?php
$pageTitle = 'About Us';
require_once __DIR__ . '/includes/header.php';
?>

<h1 class="mb-4">About TastyBites</h1>

<div class="row align-items-center mb-5">
    <div class="col-md-7">
        <p>TastyBites started in 2018 as a small family kitchen with one promise:
           food made from fresh, honest ingredients, served without pretense.</p>
        <p>Over the years we've grown into a neighborhood favorite. Our menu is short
           by design, our suppliers are local, and our welcome is always warm.</p>
        <p>Whether you're stopping by for an espresso or booking a private dinner,
           we're glad to have you.</p>
    </div>
    <div class="col-md-5">
        <div class="bg-secondary rounded" style="height: 280px;"
             aria-label="Restaurant photo placeholder"></div>
    </div>
</div>

<div class="card mb-5">
    <div class="card-body">
        <h4 class="card-title mb-3">Visit Us</h4>
        <div class="row">
            <div class="col-md-4">
                <strong>Address</strong><br>
                123 Bistro Lane<br>
                Foodtown, FT 12345
            </div>
            <div class="col-md-4">
                <strong>Phone</strong><br>
                +1 (555) 123-4567<br>
                <strong>Email</strong><br>
                hello@tastybites.local
            </div>
            <div class="col-md-4">
                <strong>Hours</strong><br>
                Mon–Sun · 11:00 – 22:00<br>
                Last reservation: 21:30
            </div>
        </div>
    </div>
</div>

<h2 class="mb-3">Meet the Team</h2>
<div class="row g-4">
    <?php
    $team = [
        ['name' => 'Marco Bianchi',  'role' => 'Head Chef'],
        ['name' => 'Lena Park',      'role' => 'Sous Chef'],
        ['name' => 'Sam O\'Connor',  'role' => 'Restaurant Manager'],
    ];
    foreach ($team as $member):
    ?>
        <div class="col-md-4">
            <div class="card text-center h-100">
                <div class="card-body">
                    <div class="bg-secondary rounded-circle mx-auto mb-3"
                         style="width: 90px; height: 90px;"
                         aria-label="Team member photo placeholder"></div>
                    <h5 class="card-title mb-1"><?= e($member['name']) ?></h5>
                    <p class="text-muted mb-0"><?= e($member['role']) ?></p>
                </div>
            </div>
        </div>
    <?php endforeach; ?>
</div>

<?php require_once __DIR__ . '/includes/footer.php'; ?>
```

## 🧹 Clean Code Reminders
- The team array sits inline (no DB needed). 3 members.
- Even though the names are static, `e()` is still used — habit.
- Placeholder blocks use neutral Bootstrap utility classes — easy to swap for real photos later.

## 🧪 Health Check

### Syntax
```bash
php -l about.php
```

### Visual tests

2. Heading + story paragraphs + image placeholder on the right.
3. "Visit Us" card with 3-column info.
4. "Meet the Team" with 3 cards (each: circular placeholder, name, role).
5. No console errors, no PHP warnings.
6. On mobile width (~400px), columns stack vertically.
