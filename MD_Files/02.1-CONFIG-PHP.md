# 02.1 — Config (`includes/config.php`)

## 📋 File Info
- **Path:** `includes/config.php`
- **Type:** Backend include, no output
- **Depends on:** Nothing (this is the root of the include chain)
- **Used by:** `includes/db.php` and `includes/auth_helpers.php` directly; every page transitively

## 🎯 Purpose
Define all environment constants (DB credentials, app constants), enable error reporting, set timezone, and start the session. The single source of truth for configuration.

## 📦 Required Behavior

1. Enable full error reporting (we're in dev/grading mode):
   ```php
   error_reporting(E_ALL);
   ini_set('display_errors', '1');
   ```
2. Set timezone: `date_default_timezone_set('Europe/Istanbul');`
3. Define DB constants (XAMPP defaults).
4. Define app constants (name, base URL, reservation hours).
5. Start the session if not already started.

## 🔧 Interface — Constants Exposed

| Constant | Value | Used For |
|---|---|---|
| `DB_HOST` | `'localhost'` | mysqli connection |
| `DB_USER` | `'root'` | mysqli connection |
| `DB_PASS` | `''` (empty string) | mysqli connection (XAMPP default) |
| `DB_NAME` | `'tastybites'` | mysqli connection |
| `APP_NAME` | `'TastyBites'` | Page titles, footer |
| `BASE_URL` | `'/tastybites'` | All asset and link paths |
| `RESERVATION_OPEN_HOUR` | `11` | First booking slot |
| `RESERVATION_CLOSE_HOUR` | `22` | Slots stop BEFORE this hour (last slot: 21:30) |
| `RESERVATION_SLOT_MINUTES` | `30` | Slot granularity |
| `RESERVATION_MAX_GUESTS` | `12` | Party size cap |
| `RESERVATION_DAYS_AHEAD` | `90` | How far into the future bookings are allowed |

## 🚫 Must NOT Do
- No DB connection here (`includes/db.php` does that).
- No function definitions (helpers live in `includes/helpers.php`).
- No HTML output. No `echo`.
- No `?>` closing tag at end of file.
- No reading from `$_SERVER` to auto-detect `BASE_URL` — hardcode it. Auto-detection causes more bugs than it fixes.

## 📐 Code Skeleton

```php
<?php
/**
 * TastyBites — Global Configuration
 * Single source of truth for environment constants, error reporting,
 * timezone, and session bootstrap.
 */

// ---------- Error Reporting (dev mode) ----------
error_reporting(E_ALL);
ini_set('display_errors', '1');

// ---------- Timezone ----------
date_default_timezone_set('Europe/Istanbul');

// ---------- Database ----------
define('DB_HOST', 'localhost');
define('DB_USER', 'root');
define('DB_PASS', '');
define('DB_NAME', 'tastybites');

// ---------- Application ----------
define('APP_NAME', 'TastyBites');
define('BASE_URL', '/tastybites');

// ---------- Reservation Rules ----------
define('RESERVATION_OPEN_HOUR', 11);
define('RESERVATION_CLOSE_HOUR', 22);
define('RESERVATION_SLOT_MINUTES', 30);
define('RESERVATION_MAX_GUESTS', 12);
define('RESERVATION_DAYS_AHEAD', 90);

// ---------- Session ----------
if (session_status() === PHP_SESSION_NONE) {
    session_start();
}
```

## 🧹 Clean Code Reminders
- Section comments above each block (Error / Timezone / Database / Application / Reservation / Session).
- Constants grouped logically.
- No trailing whitespace.

   SESSION=2

4. **Delete `_configtest.php` after verifying.**
