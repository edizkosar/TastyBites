# 08.4 — Reservation Manager (`admin/reservation_manage.php`)

## 📋 File Info
- **Path:** `admin/reservation_manage.php`
- **Type:** Protected admin page. GET list + POST status-change endpoint.
- **Depends on:** `includes/db.php`, `includes/helpers.php`, `includes/auth_helpers.php`, layout includes
- **Used by:** Admin role only

## 🎯 Purpose
List all reservations with filtering (by status, date range) and let the admin change a reservation's status inline (`pending → confirmed`, `pending → cancelled`, `confirmed → completed`, etc.).

## 📦 Required Behavior

### Auth gate
`requireAdmin();` first.

### Filter form (GET)
Three inputs in a row at the top:
- `status` (select: `''` All / `pending` / `confirmed` / `cancelled` / `completed`)
- `date_from` (date)
- `date_to` (date)

Filters are AND-combined. Empty fields = no filter.

### List query
Build a dynamic WHERE with prepared statement. Types and bindings:
```php
$conditions = [];
$params     = [];
$types      = '';
if ($statusFilter !== '')   { $conditions[] = 'r.status = ?';            $params[] = $statusFilter; $types .= 's'; }
if ($dateFrom !== '')       { $conditions[] = 'r.reservation_date >= ?'; $params[] = $dateFrom;     $types .= 's'; }
if ($dateTo !== '')         { $conditions[] = 'r.reservation_date <= ?'; $params[] = $dateTo;       $types .= 's'; }

$sql = "SELECT r.id, r.reservation_date, r.reservation_time, r.party_size, r.status,
               r.special_request, r.created_at,
               u.full_name, u.email, u.phone,
               t.table_number
        FROM reservations r
        JOIN users u  ON u.id = r.user_id
        JOIN tables t ON t.id = r.table_id";
if (!empty($conditions)) { $sql .= ' WHERE ' . implode(' AND ', $conditions); }
$sql .= ' ORDER BY r.reservation_date DESC, r.reservation_time DESC LIMIT 200';

$stmt = $db->prepare($sql);
if ($types !== '') { $stmt->bind_param($types, ...$params); }
$stmt->execute();
$rows = $stmt->get_result()->fetch_all(MYSQLI_ASSOC);
$stmt->close();
```

### Status change action
`POST` with `action=update_status`, `id`, and `new_status`. Server:
1. Validate `new_status` ∈ {`pending`, `confirmed`, `cancelled`, `completed`}.
2. UPDATE the row.
3. Flash + redirect back, preserving filter query string.

Rendered inline per row as a small `<form>` with a `<select>` that auto-submits when changed:
```html
<form method="post"
      action="<?= BASE_URL ?>/admin/reservation_manage.php?action=update_status&<?= http_build_query($filterQuery) ?>"
      class="d-inline">
    <input type="hidden" name="id" value="<?= (int)$r['id'] ?>">
    <select name="new_status" class="form-select form-select-sm"
            onchange="this.form.submit()">
        <?php foreach (['pending','confirmed','cancelled','completed'] as $s): ?>
            <option value="<?= e($s) ?>" <?= $r['status'] === $s ? 'selected' : '' ?>>
                <?= e(ucfirst($s)) ?>
            </option>
        <?php endforeach; ?>
    </select>
</form>
```

### Table columns
ID / Created / Customer (name + email + phone) / Table / Date & Time / Party / Status (interactive select) / Special Request.

## 🚫 Must NOT Do
- Don't allow free-text status input — only the 4 enum values.
- Don't let admin delete reservations from this page (status `cancelled` is the soft-delete).
- Don't show more than 200 rows — for student-scale dataset that's plenty.
- Don't add bulk operations (multi-select, etc.).

## 📐 Code Skeleton

```php
<?php
require_once __DIR__ . '/../includes/db.php';
require_once __DIR__ . '/../includes/helpers.php';
require_once __DIR__ . '/../includes/auth_helpers.php';

requireAdmin();

$allowedStatuses = ['pending', 'confirmed', 'cancelled', 'completed'];

// ============ STATUS UPDATE ============
if (($_GET['action'] ?? '') === 'update_status' && currentMethod() === 'POST') {
    $id        = (int)($_POST['id'] ?? 0);
    $newStatus = $_POST['new_status'] ?? '';

    if ($id <= 0 || !in_array($newStatus, $allowedStatuses, true)) {
        setFlash('Invalid status update.', 'danger');
    } else {
        $stmt = $db->prepare("UPDATE reservations SET status = ? WHERE id = ?");
        $stmt->bind_param('si', $newStatus, $id);
        $stmt->execute();
        $stmt->close();
        setFlash('Reservation status updated.', 'success');
    }

    // Preserve filter query string in the redirect.
    $qs = $_POST;
    unset($qs['action'], $qs['id'], $qs['new_status']);
    $tail = !empty($qs) ? '?' . http_build_query($qs) : '';
    redirect('/admin/reservation_manage.php' . $tail);
}

// ============ LIST WITH FILTERS ============
$statusFilter = $_GET['status']    ?? '';
$dateFrom     = $_GET['date_from'] ?? '';
$dateTo       = $_GET['date_to']   ?? '';

// Sanity-check status filter
if ($statusFilter !== '' && !in_array($statusFilter, $allowedStatuses, true)) {
    $statusFilter = '';
}

$conditions = [];
$params     = [];
$types      = '';
if ($statusFilter !== '') { $conditions[] = 'r.status = ?';            $params[] = $statusFilter; $types .= 's'; }
if ($dateFrom !== '')     { $conditions[] = 'r.reservation_date >= ?'; $params[] = $dateFrom;     $types .= 's'; }
if ($dateTo !== '')       { $conditions[] = 'r.reservation_date <= ?'; $params[] = $dateTo;       $types .= 's'; }

$sql = "SELECT r.id, r.reservation_date, r.reservation_time, r.party_size, r.status,
               r.special_request, r.created_at,
               u.full_name, u.email, u.phone,
               t.table_number
        FROM reservations r
        JOIN users u  ON u.id = r.user_id
        JOIN tables t ON t.id = r.table_id";
if (!empty($conditions)) { $sql .= ' WHERE ' . implode(' AND ', $conditions); }
$sql .= ' ORDER BY r.reservation_date DESC, r.reservation_time DESC LIMIT 200';

$stmt = $db->prepare($sql);
if ($types !== '') { $stmt->bind_param($types, ...$params); }
$stmt->execute();
$rows = $stmt->get_result()->fetch_all(MYSQLI_ASSOC);
$stmt->close();

$filterQuery = array_filter([
    'status'    => $statusFilter,
    'date_from' => $dateFrom,
    'date_to'   => $dateTo,
], fn($v) => $v !== '');

function statusBadgeClass(string $status): string
{
    return match ($status) {
        'pending'   => 'bg-warning text-dark',
        'confirmed' => 'bg-success',
        'cancelled' => 'bg-secondary',
        'completed' => 'bg-info text-dark',
        default     => 'bg-light text-dark',
    };
}

$pageTitle = 'Manage Reservations';
require_once __DIR__ . '/../includes/header.php';
?>

<h1 class="mb-4">Manage Reservations</h1>

<form method="get" action="<?= BASE_URL ?>/admin/reservation_manage.php" class="row g-2 mb-4">
    <div class="col-md-3">
        <label for="status" class="form-label">Status</label>
        <select id="status" name="status" class="form-select">
            <option value="">All</option>
            <?php foreach ($allowedStatuses as $s): ?>
                <option value="<?= e($s) ?>" <?= $statusFilter === $s ? 'selected' : '' ?>>
                    <?= e(ucfirst($s)) ?>
                </option>
            <?php endforeach; ?>
        </select>
    </div>
    <div class="col-md-3">
        <label for="date_from" class="form-label">Date From</label>
        <input type="date" id="date_from" name="date_from" class="form-control"
               value="<?= e($dateFrom) ?>">
    </div>
    <div class="col-md-3">
        <label for="date_to" class="form-label">Date To</label>
        <input type="date" id="date_to" name="date_to" class="form-control"
               value="<?= e($dateTo) ?>">
    </div>
    <div class="col-md-3 d-flex align-items-end">
        <button type="submit" class="btn btn-primary me-2">Filter</button>
        <a href="<?= BASE_URL ?>/admin/reservation_manage.php" class="btn btn-link">Reset</a>
    </div>
</form>

<p class="text-muted">Showing <?= count($rows) ?> reservation(s).</p>

<div class="table-responsive">
    <table class="table align-middle table-sm">
        <thead>
            <tr>
                <th>#</th>
                <th>Created</th>
                <th>Customer</th>
                <th>Table</th>
                <th>Date &amp; Time</th>
                <th>Party</th>
                <th>Status</th>
                <th>Request</th>
            </tr>
        </thead>
        <tbody>
        <?php if (empty($rows)): ?>
            <tr><td colspan="8" class="text-center text-muted">No reservations match the filters.</td></tr>
        <?php else: foreach ($rows as $r): ?>
            <tr>
                <td>#<?= (int)$r['id'] ?></td>
                <td class="small text-muted"><?= e($r['created_at']) ?></td>
                <td>
                    <?= e($r['full_name']) ?>
                    <small class="d-block text-muted"><?= e($r['email']) ?></small>
                    <?php if (!empty($r['phone'])): ?>
                        <small class="d-block text-muted"><?= e($r['phone']) ?></small>
                    <?php endif; ?>
                </td>
                <td>Table #<?= (int)$r['table_number'] ?></td>
                <td><?= e(formatReservationDateTime($r['reservation_date'], $r['reservation_time'])) ?></td>
                <td><?= (int)$r['party_size'] ?></td>
                <td>
                    <span class="badge <?= statusBadgeClass($r['status']) ?> mb-1 d-inline-block">
                        <?= e(ucfirst($r['status'])) ?>
                    </span>
                    <form method="post"
                          action="<?= BASE_URL ?>/admin/reservation_manage.php?action=update_status<?= !empty($filterQuery) ? '&' . http_build_query($filterQuery) : '' ?>"
                          class="d-inline">
                        <input type="hidden" name="id" value="<?= (int)$r['id'] ?>">
                        <?php foreach ($filterQuery as $k => $v): ?>
                            <input type="hidden" name="<?= e($k) ?>" value="<?= e($v) ?>">
                        <?php endforeach; ?>
                        <select name="new_status" class="form-select form-select-sm"
                                onchange="this.form.submit()">
                            <?php foreach ($allowedStatuses as $s): ?>
                                <option value="<?= e($s) ?>" <?= $r['status'] === $s ? 'selected' : '' ?>>
                                    <?= e(ucfirst($s)) ?>
                                </option>
                            <?php endforeach; ?>
                        </select>
                    </form>
                </td>
                <td class="small text-muted"><?= e($r['special_request'] ?? '') ?></td>
            </tr>
        <?php endforeach; endif; ?>
        </tbody>
    </table>
</div>

<?php require_once __DIR__ . '/../includes/footer.php'; ?>
```

## 🧹 Clean Code Reminders
- Dynamic WHERE building is done with arrays + `implode(' AND ', ...)` — readable, prepared, safe.
- `statusBadgeClass()` duplicated across admin/user pages — accept that (tiny function, scoped to file).
- `array_filter(..., fn($v) => $v !== '')` keeps the filter query slim.

## 🧪 Health Check

### Syntax
```bash
php -l admin/reservation_manage.php
```

### Functional tests
1. Logged out / regular user → blocked.
2. Empty filters → all reservations listed, sorted by date DESC.
3. Filter `status = pending` → only pending rows.
4. Filter `date_from = today, date_to = today+30` → only matching rows.
5. Pick a `pending` row → change status select to `confirmed` → page reloads with updated badge and "Reservation status updated." flash. Filter query preserved in URL.
6. Tamper `new_status=evil` via DevTools → "Invalid status update." flash. Row unchanged.
7. After confirming a future reservation, log in as the customer → dashboard shows `confirmed` badge.
8. Reset link clears all filters → URL becomes the bare page.

### Edge cases
9. `date_from` AFTER `date_to` → produces an empty result (no crash).
10. `status = foo` (bad value) → silently treated as "all" (sanity check on filter side).
