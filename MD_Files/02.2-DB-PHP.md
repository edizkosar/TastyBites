# 02.2 — Database Connection (`includes/db.php`)

## 📋 File Info
- **Path:** `includes/db.php`
- **Type:** Backend include, no output
- **Depends on:** `includes/config.php`
- **Used by:** Every PHP file that runs a SQL query

## 🎯 Purpose
Open a single MySQLi connection using the constants from `config.php` and expose it as `$db`. Fail loudly with a generic message if the connection breaks.

## 📦 Required Behavior

1. `require_once` `config.php`.
2. Create a new `mysqli` instance with `DB_HOST`, `DB_USER`, `DB_PASS`, `DB_NAME`.
3. If `connect_errno` is set → `die('Database connection failed.');` (generic — never leak credentials).
4. Set charset to `utf8mb4` on the connection.
5. Leave `$db` in scope for the including file.

## 🔧 Interface

Exposes one variable:
- `$db` — a connected `mysqli` instance.

That's it. No functions, no classes.

## 🚫 Must NOT Do
- No queries here. Just open the connection.
- No `echo` of any DB error details (credentials, hostnames).
- No persistent connections (`p:localhost`).
- No try/catch wrapping `new mysqli()` — `connect_errno` is the correct check.
- No closing `?>` tag.

## 📐 Code Skeleton

```php
<?php
/**
 * TastyBites — Database Connection
 * Opens a single mysqli connection and exposes it as $db.
 */

require_once __DIR__ . '/config.php';

$db = new mysqli(DB_HOST, DB_USER, DB_PASS, DB_NAME);

if ($db->connect_errno) {
    // Do not leak details. Log internally if needed in real production.
    die('Database connection failed.');
}

$db->set_charset('utf8mb4');
```
