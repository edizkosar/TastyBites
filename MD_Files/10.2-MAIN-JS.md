# 10.2 — Site JavaScript (`assets/js/main.js`)

## 📋 File Info
- **Path:** `assets/js/main.js`
- **Type:** Vanilla JavaScript (no module system, no framework)
- **Depends on:** Browser DOM API only. Loaded AFTER Bootstrap JS in `includes/footer.php`.
- **Used by:** Every page (included via footer)

## 🎯 Purpose
A tiny piece of progressive enhancement: set the `min` attribute on date inputs marked `data-min-today` to today's date, and gently fade out flash alerts after 4 seconds.

## 📦 Required Behavior

When the DOM is ready:

1. Find every `<input data-min-today>` and set its `min` attribute to today's date in `YYYY-MM-DD`.
2. Find every `div.alert` inside the flash container that isn't `.alert-dismissible` and isn't `.tb-no-fade`.
   - After 4 seconds, add the class `tb-fade-out` (CSS handles the opacity transition).
   - After 4.5 seconds total, remove the element from the DOM.

Both pieces are **enhancements**, not requirements. The server still validates the date; the alert still works without auto-fade.

## 🔧 Interface
No globals exposed. No window-level functions. Self-contained IIFE or top-level `document.addEventListener('DOMContentLoaded', ...)` block.

## 🚫 Must NOT Do
- No jQuery. Vanilla DOM API only.
- No remote fetches / no AJAX.
- No event listeners that block form submission (we use `onsubmit="return confirm(...)"` inline on those forms — JS file does not interfere).
- No `console.log` debug statements left in production.
- No automatic localStorage / cookie writes.
- No ES module imports / exports.

## 📐 Code Skeleton

```javascript
/**
 * TastyBites — Tiny site JavaScript.
 * - Sets the min date on inputs marked [data-min-today].
 * - Fades out flash alerts after 4 seconds.
 */
(function () {
    'use strict';

    function setMinDateOnDateInputs() {
        var inputs = document.querySelectorAll('input[data-min-today]');
        if (inputs.length === 0) { return; }
        var today = new Date();
        var yyyy = today.getFullYear();
        var mm   = String(today.getMonth() + 1).padStart(2, '0');
        var dd   = String(today.getDate()).padStart(2, '0');
        var iso  = yyyy + '-' + mm + '-' + dd;
        for (var i = 0; i < inputs.length; i++) {
            inputs[i].setAttribute('min', iso);
        }
    }

    function autoFadeAlerts() {
        // Only fade alerts that are inside .container > .alert
        // and not marked .alert-dismissible (which has its own close button)
        // and not marked .tb-no-fade.
        var alerts = document.querySelectorAll(
            '.container > .alert:not(.alert-dismissible):not(.tb-no-fade)'
        );
        if (alerts.length === 0) { return; }
        alerts.forEach(function (el) {
            setTimeout(function () {
                el.classList.add('tb-fade-out');
            }, 4000);
            setTimeout(function () {
                if (el.parentNode) {
                    el.parentNode.removeChild(el);
                }
            }, 4500);
        });
    }

    document.addEventListener('DOMContentLoaded', function () {
        setMinDateOnDateInputs();
        autoFadeAlerts();
    });
})();
```
