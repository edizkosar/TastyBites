# 04.3 — Logout Endpoint (`auth/logout.php`)

## 📋 File Info
- **Path:** `auth/logout.php`
- **Type:** Endpoint (no HTML output)
- **Depends on:** `includes/config.php`, `includes/helpers.php`
- **Used by:** "Logout" link in navbar

## 🎯 Purpose
Destroy the current session, start a fresh one (to carry the flash message), set a goodbye flash, and redirect home.

## 📦 Required Behavior

1. Include `config.php` (starts/uses session) and `helpers.php` (for `setFlash` / `redirect`).
2. Clear the `$_SESSION` array.
3. Destroy the session.
4. Start a new session (so `setFlash` can write to it).
5. Set flash: `'You have been logged out.'` (type `'info'`).
6. Redirect to `/index.php`.

## 🔧 Interface
None — this is a "fire and forget" endpoint. URL accessed → side effects → redirect.

## 🚫 Must NOT Do
- Don't render any HTML.
- Don't require any form submission — a plain `<a href>` link to this URL is fine because there's no destructive DB write.
- Don't accept query parameters.
- Don't include `header.php` / `footer.php`.

## 📐 Code Skeleton

```php
<?php
/**
 * TastyBites — Logout
 * Destroys the current session, sets a goodbye flash, redirects home.
 */

require_once __DIR__ . '/../includes/config.php';
require_once __DIR__ . '/../includes/helpers.php';

// Clear all session variables.
$_SESSION = [];

// Destroy the session.
session_destroy();

// Start a fresh session for the flash message.
session_start();
setFlash('You have been logged out.', 'info');

redirect('/index.php');
```

## 🧹 Clean Code Reminders
- 6 lines of executable code. That's it.
- Comments explain the why (clear → destroy → fresh start for flash).

## 🧪 Health Check

### Syntax
```bash
php -l auth/logout.php
```

### Functional tests
1. Log in as any user.
2. Click the "Logout" link in the navbar.
3. Browser lands on `/index.php` (or its 404 until Module 05.1 exists — that's fine).
4. The flash "You have been logged out." appears on the next page that renders the layout.
5. Reload any page → navbar shows "Login" / "Register" again.
6. Run `_authtest.php` from Module 02.4 (or recreate temporarily) → `isLoggedIn() = false`.

### Edge cases
7. Hit `/auth/logout.php` directly while not logged in → no error, just redirected home with the flash. (Destroying a non-existent session is a no-op; nothing to crash on.)
